# 飞书网页版编辑操作清单

## 输入方式

`draft.md` 保存的是实际要粘贴的纯文本正文。文件扩展名为 `.md`，但正文不依赖 Markdown 导入或自动转换，也没有 HTML、Mermaid 或编辑提示混入正文。

1. 在本地文本编辑器中打开 `draft.md`，复制文件内容，粘贴到飞书文档正文的空白处。若编辑器提供“粘贴为纯文本”，使用该方式，避免带入本地编辑器的样式。
2. 将文档顶部的标题栏设为“支付服务上线方案”。正文首行同名文字保留，选中该整行，通过编辑器的段落样式菜单设置为“一级标题”。
3. 下面的格式需要用编辑器原生功能逐项设置。不要假定粘贴后它们已经生成。各版本菜单名称可能不同，应按对应功能定位；本任务未打开浏览器核对菜单位置。

## 标题层级

将以下五个独立段落分别设置为“二级标题”：

- 上线目标
- 风险与控制
- 项目与负责人
- 上线检查代码
- 上线流程

检查正文首行为一级标题、五个章节为二级标题，段落前没有残留的 `#` 字符。

## 风险高亮块

1. 将光标放在独立的“风险：回调重试可能导致重复记账”段落。
2. 使用编辑器的块类型菜单或插入菜单，选择“高亮块／提示块”对应功能；若无法直接转换该段落，在附近插入高亮块，将这句话剪切到块内。
3. 将该块设为醒目的黄色或橙色背景。下一段“上线前确认……”仍保持普通正文。
4. 检查风险文字在一个独立的原生高亮块内。仅给文字加背景色、使用引用块或加粗，并不等于完成此项。

## 原生表格

正文中三个带制表符的文本行仅是待输入的数据，普通粘贴不保证生成原生表格。

1. 在“项目与负责人”标题下，使用编辑器“插入表格”功能，创建 **3 列 × 3 行** 的原生表格。
2. 逐格输入以下内容；不要把 Markdown 管道表格贴入正文，也不要把三行数据留作文字表格。

| 行 | 第 1 列 | 第 2 列 | 第 3 列 |
| --- | --- | --- | --- |
| 第 1 行 | 项目 | 负责人 | 状态 |
| 第 2 行 | 幂等校验 | 小林 | 完成 |
| 第 3 行 | 灰度验证 | 小周 | 待验证 |

3. 将第一行设为表头，或至少加粗该行。确认九个单元格都正确后，删除正文中原来那三行带制表符的文本。
4. 点击各单元格，确认可以独立编辑；检查列数、行数、内容顺序，以及“小周”的状态确实是“待验证”。

## 带语言标记的 Python 代码块

1. 在“上线检查代码”下使用编辑器“插入代码块”功能。
2. 将独立段落 `print('ready')` 剪切进代码块，并在代码块的语言选择器中选择 **Python**。若编辑器支持将当前段落直接转换为代码块，也可以转换后再选择语言。
3. 检查代码块语言显示为 Python，代码内容仍是 `print('ready')`，单引号没有变成中文引号或弯引号，普通正文中没有重复代码。
4. 不要将三个反引号或 `python` 字样当成代码正文；本文件没有提供可自动导入的代码围栏。

## 关键日期下划线

1. 在“上线目标”的正文中，精确选中 `2026-10-15`。
2. 使用浮动文字工具栏或格式菜单的“下划线”功能。
3. 取消选区后检查该日期的十个字符全部带下划线，左右文字没有被一并加下划线。不要输入 `<u>` 标签，也不要将下划线字符放在日期前后代替文字格式。

## 步骤图示

`draft.md` 已包含三框两箭头的 Unicode 图示，按“校验 → 灰度 → 全量”从左到右排列，不需要 Mermaid 渲染器。

1. 检查三框和两根箭头粘贴后仍完整，箭头都指向右侧，文字顺序正确。
2. 若比例字体或窄窗口导致图框错位，将这三行图示放入独立代码块，选择“纯文本／Plain Text”，用等宽字体保留排版；该图示块与上方的 Python 代码块是两个不同的块。关闭图示块换行（若有该选项），或确保显示宽度足够。
3. 若当前编辑器提供原生流程图／绘图块，可将文本图示替换为原生图示：插入三个矩形框，从左至右输入“校验”“灰度”“全量”，用两根向右的箭头连接相邻框；检查完成后删除原文本图示。该项是可选改进，不以该功能存在作为完成任务的前提。
4. 检查最终文档至少显示一份清楚的三步骤图示，没有把 Mermaid 源码当成已渲染图示，也没有留下重复图示。

## 最终检查

- 文档标题、正文一级标题和五个二级标题均已设置。
- 风险句子完整地位于原生高亮块内。
- 表格是可点击单元格的 3 列 × 3 行原生表格，表头和两行数据正确。
- `print('ready')` 位于原生代码块内，语言选择为 Python。
- `2026-10-15` 显示实际下划线。
- 图示清晰显示“校验 → 灰度 → 全量”，框和箭头没有断裂或错位。
- 删除已被原生块替换的占位文字后，正文无重复表格、代码或图示。
