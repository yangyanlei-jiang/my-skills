1. 按已授权批量 Markdown 工具的契约，将 `draft.md` 转换为可编辑的飞书原生文档。若接口提供标题字段，将首行“上线方案”映射到该字段，并从正文移除首行；批量转换标题、有序列表、管道表格与 Python 代码块。

3. 集中验收原生表格为 **3 行 × 3 列**、九个单元格内容和加粗样式准确，列表正确，代码原样为 `print("ready")` 且语言为 Python，并查看日期下划线和风险高亮块的实际结果。无需重建已正确转换的表格或逐段排版；结果不明时先核实，再局部修正。
