# 写入方法

离线草稿已准备，尚未写入飞书。

1. 按已授权批量 Markdown 工具的契约，将 `draft.md` 转换为可编辑的飞书原生文档。若接口提供标题字段，将首行“上线方案”映射到该字段，并从正文移除首行。保留 `<u>`、`<callout>` 扩展及 `python` 代码围栏。
2. 用原生读回集中验收：标题、有序列表、表格为 **3 行 × 3 列**且九个单元格内容准确，表头与“完成”保留加粗；日期具有下划线；风险为原生高亮块；代码原样为 `print("ready")`，语言为 Python。
3. 当前转换能力覆盖全部要求，无预定浏览器补齐项。只有读回发现缺失时才修正对应局部；结果不明时先读回，再补缺项。
