# 离线写入计划

本计划及 draft.md 均为离线产物，尚未创建或写入飞书文档，也未验证真实渲染。依据同目录 skill-snapshot/SKILL.md 及其引用资料拟定；能力判断采用请求中提供的工具说明，不假定额外 API 字段或工具名。

## 格式与路径

批量 Markdown 写入工具已经获授权，明确支持标题、列表、管道表格转为原生文档富文本表格，以及代码块语言。用它一次写入正文。其不支持的原生高亮块和下划线，由浏览器完成。

draft.md 第一行是文档名称，写入时将“上线方案”设为文档标题字段，移除正文中的第一行及随后的空行；正文从“计划上线日期”开始。标题使用当前已提供的文档创建或标题入口，不编造其参数。如果批量工具未暴露标题字段，只在浏览器标题区域设置该名称。

风险句和日期在 Markdown 草稿中保留为普通文本；它们是后续原生格式操作的精确目标。不用引用块、底色、HTML 或双下划线冒充指定格式。

## 具体写入顺序

1. 以“上线方案”为标题创建目标飞书原生文档，并记录工具实际返回的文档身份及链接。执行前核对实际工具契约中的目标、大小限制及返回方式；沿用已授权写入能力，不增加分享或通知操作。
2. 将 draft.md 去除文档名称后的全部正文交给批量 Markdown 写入工具，保持原顺序：日期段落、上线步骤标题及三项有序列表、检查记录标题及表格、风险标题及风险句、就绪检查标题及 Python 代码块。
3. 根据写入返回结果记录真实块或单元格身份。若返回失败、超时或结果不明，先读回目标内容，确认已有段落和表格，再补写缺项，避免整篇重复写入。
4. 从返回链接进入浏览器，读取当前页面和可访问元素，确认文档身份及编辑权限。准确定位风险标题下的唯一句子“回调重试可能导致重复记账。”，用当前编辑器的原生高亮块插入或转换功能，将该句设为原生 callout。若只能插入新块，先创建并填入该句，核对后删除原普通段落，保持原位置且只出现一次。
5. 在日期段落中仅选中“2026-10-15”，通过当前样式工具栏显式应用下划线，保留周围文字和段落类型。
6. 通过工具可靠的结构化读回或浏览器渲染验收：文档标题为“上线方案”；四个正文章节为二级标题；上线步骤是三个有序列表项；表格是原生文档富文本表格且为 3 行 × 3 列（表头计一行）；九个单元格分别为项目/负责人/状态、幂等校验/小林/完成、灰度验证/小周/待验证；风险句位于真正的高亮块且只出现一次；仅日期数字有下划线；代码内容为 print("ready") 且语言为 Python。
7. 确认保存完成后，交付实际文档链接和简短验收结果。若某项缺少可观察证据，明确该项尚未验证；不能仅凭写入成功或纯文本读回宣称格式通过。

## 浏览器操作范围

内容修改仅限风险句转换为原生高亮块、日期数字应用下划线；只有批量工具不提供标题字段时，再设置文档标题。浏览器可以检查整篇渲染与保存状态，必要时修正已确认失败的上述局部格式。已由批量工具正确生成的标题、步骤、原生表格和 Python 代码块无需重新输入或重新创建。全部操作在已确认的同一文档内进行。

本次离线评估未打开浏览器、联网或调用真实服务；上述顺序是后续执行方法。
