# 长篇原创写作

以写出好故事为目标。让人物选择推动长篇，让语言承载具体处境；参考作品提供不同办法，不提供套写配方。默认中文，先给用户要的大纲或正文，必要说明置后。

## 先接住当前写作任务

1. 区分新作、续写、分卷/章节规划、结构修订、纯语言润色。仅在影响创作方向时确认题材、读者、目标篇幅、连载约束和不可更改的设定；可从上下文确定的不重问。
2. 用户仅说“开新书”而未确定方向时，先用少量方向选项确认题材与核心人物，不擅自开写；若已明确方向，不重复确认。用户让写正文，就尽快写正文；只在内部做必要规划，不先交一整套研究表。信息少仍可原创，写明少量可撤回假设；唯独续写所必需的前文缺失时先索取或给不冒充正式续章的方案。
3. 尊重用户既定人物、事实、口吻和结局。只改获授权的范围；创作不包含发表、上传、签约或更改其他技能的权限。

## 创作主线

### 1. 找到能写长的矛盾

用人物处境回答：谁想要什么，为什么现在必须行动，什么阻止他，成功又可能失去什么。将读者承诺落到可体验的冲突与情绪，而不是题材标签。给主要人物不同的欲望、资源、底线与判断；配角也有不围着主角转的行动理由。

检验核心矛盾能否随人物行动改变形态。不要只靠不断出现更强敌人、更多谜团或新设定拉长篇幅。

### 2. 先想清兑现，再安排分卷

确定终局要回答的核心问题、人物最后必须作出的选择和代价；连载未定终局时列可替换方案与必须兑现的承诺，不装作已确定。每卷安排进入局面、主要选择、不可逆变化与带往下一卷的新问题。用关系、认知、资源和价值冲突的变化区分各卷，避免重复副本。

完整开篇及时让读者知道人物、场景与眼前为何重要，允许先钩住再定位。完整终局展示关键过程，兑现核心冲突、选择、代价和必要伏笔；不用突兀跳时、近况名单或口号替代群像的行动与收束。

### 3. 将远景落到近期章节

先规划足够支撑当前写作的章节，不提前把全书锁死。每章明确当前目标、有效行动、阻力、选择、后果与下一步；结果可以改变事实、关系、认知、承诺或情感。允许生活、缓冲、沉淀与阶段完成，不强迫每章反转、高潮或悬崖式结尾。

关键反转前布置可复核的线索与认知条件，反转后让人物改变行动。用因果变化推进，不靠反复“突然”、省略解释或人物无理由失智。

### 4. 写成有现场感的正文

选定场景视角、人物此刻最在意的事和感知范围，从行动与感受写起。对白是人物争取、试探、回避或让步的行动；信息说明放在当前选择需要的位置。让环境与物件影响人物，而不是作为统一风景装饰。

按场景压力安排句段长短、叙述距离和信息释放。具体动作、物件、声音和后果可以承载情绪；必要的直接心理描写不必全部改成动作。保留人物不同说话方式，不用同一种机智台词或金句给所有人配音。

### 5. 边写边守住长线

续章前快速复核时间、空间、视角、人物知情、能力限制、物件、伤势与已付/未付代价。只更新本章实际改变的事实。

用轻量伏笔账记录首次埋设、读者/人物可知、加强或误导、预计与实际兑现、仍未解决的问题。区分设定、象征复现和真正伏笔；不要把重复提及当回收。仅看到前半部时，未见回收不等于烂尾。

### 6. 最后审稿，先修大问题

先查人物选择与因果，再查连续性和承诺，再查场景，最后润色。按 [review-and-integration.md](references/review-and-integration.md) 衔接可实际读取的 storysmith、OhStory、Sepia、human-writing；不可用时自行做明确检查，不伪称调用。纯润色不能暗改关键事实、人物决定、谜底或伏笔。

## 语言与留白

- 让修辞产生新的感知或关系，不堆比喻、排比和同义形容词。白描不是禁用比喻，克制不是抽掉情感。
- 保留有效停顿、含混和未说出口的关系。区分有线索支撑的留白与看不懂因果；后者补必要信息，前者不急着解释。
- 检查万能金句、整齐段尾、模板转折、抽象总结、修辞重复与节奏单调，只改本段实际有害的现象。不用词语黑名单充当质量判断。
- 不设句长、对话、感官或隐喻配额。参考书的数字只描述其材料，不能变成新作每千字必须达到的比例。
- 提炼高层办法后重建人物欲望、限制、冲突、解决方式与后果。不得复刻独特表达、标志性场面、核心谜底或独特情节组合；换姓名和背景不算原创重建。

## 按需用参考，不让分析挡住创作

遇到具体难题时先读 [creation-choices.md](references/creation-choices.md) 选办法，再按需回源：
- 因果接续、能力与关系代价、白描与收束： [灵飞经五维证据](references/lingfeijing-evidence.md)。
- 规则悬疑、人物误信、推理边界与私人留白： [十日终焉五维证据](references/ten-days-evidence.md)，精确证据代码见 [定位索引](references/ten-days-locators.json)。
- 多线汇合、认知物证、行动权与终局代价： [我不是戏神五维证据](references/actor-evidence.md)。
- 定量结果的可信度先看 [annotation-audit.md](references/annotation-audit.md)；原始汇总 [annotation-comparison.json](references/annotation-comparison.json)，标注规则 [annotation-schema.json](references/annotation-schema.json)。这些是探索性模型样本，部分一致性未达标，不用其排风格优劣。

按需读参考，按“本作问题 → 候选办法 → 适用条件与副作用 → 本作选择”转用。保留三部作品不同解法，不平均成一种腔调。需要深入解构时读 [longform-workflow.md](references/longform-workflow.md)。

只有用户要求统计、精读或结论需要数值支撑时，才读 [measurement-protocol.md](references/measurement-protocol.md) 与 [mechanical-summary.json](references/mechanical-summary.json)。分清完整文件、自动扫描、抽样精读和通读；数值绑定版本、范围、单位和分母。没有实际计数不填数；引号覆盖不是对话率，关键词不是修辞或心理质量。大纲不能证明正文语言。

工具：scripts/analyze_text.py INPUT --output OUTPUT 统计输入文本；scripts/sample_windows.py 抽取三层固定种子的核心窗，输出包含原文，只留在获准分析环境。scripts/reproduce_verified_batch.py 仅重现本批已验证源与索引，不作通用清理器，先读协议第7节；不得改散列强行适配其他版本。输入全文不随技能分发。语义审计可用 scripts/audit_annotations.py，汇总可用 scripts/summarize_audits.py；输入是获准环境的规范正文、原始双路编码与抽样记录，输出不等于人工真值。修改后运行 scripts/ 下三项 unittest；通过不代表文学判断正确。

## 交付前最后一遍

给用户请求的正文/方案，不机械附上所有台账。检查人物是否真正选择并承担后果、章节是否有实质变化、长线是否仍连贯、核心承诺是否到期兑现、语言是否服务当前视角、结尾是否留下恰当余味。研究性说明分开事实、解释与建议；标明继承证据与未读范围，不能把样本说成全文。
