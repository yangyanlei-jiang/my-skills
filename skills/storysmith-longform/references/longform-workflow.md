# 长篇工作流与分析单位

## 1. 证据先于命名

给材料建立稳定定位：作品/版本、章节序号与标题、段落序号；有本地规范文本时补充行号或字符区间及 SHA-256。网页位置会变，章节名重复，不能只给模糊的“中后期”。原文短引只用于定位与讨论，不汇成可复用句库。

为重要结论建立记录：

- 观察：实际发生或呈现了什么；注明范围。
- 解释：这个选择可能如何作用于阅读；允许多种解释。
- 支持位置与反证位置：若尚未找到反例，写“该覆盖范围内未检出”，不是“没有”。
- 迁移条件：何种人物处境、叙述视角或篇幅下可用。
- 不适用情境：该机制何时制造违和、拖延或信息作弊。
- 原创决策：面对新作品具体难题，如何取舍；不套用来源的故事细节。

## 2. 全书与分卷

先问开篇让读者追问什么，结局或已见最末章改变了什么。区分外部目标、身份/关系变化与价值冲突。大谜团、情感承诺、能力成长、社会处境可同时存在，不强迫归为单一主线。

绘制“进入本卷时的局面 → 主动选择 → 阻力/新信息 → 不可逆后果 → 带往下卷的未决问题”。卷边界按叙事变化判读；作者标注的卷与分析分段不一致时并列标明，不能冒称原书分卷。

检验中段：升级是否改变目标、限制、关系或行动代价，而非仅扩大敌人数值？支线是否在主角缺席时仍有自己的因果？阶段性兑现是否让读者得到实质答案，同时打开不同层次的问题？不要预设三幕、固定百分比或固定高潮位置。

## 3. 章节与场景

以状态变化为基本单位：角色起始掌握什么、想要什么、做了什么、承担什么、结束时什么不可复原。叙事状态可以是事实、关系、认知、承诺、资源、情感或道德立场，并不限于物理行动。

区分场景中的因果推进、回顾说明、生活纹理与必要缓冲。不是每章都需要危机；低压力章节仍可改变读者对角色/世界的理解。审查重复：相邻章节是否用同种阻碍、同样误会和相同段尾句式制造虚假推进。

记录章尾功能而非一律叫“钩子”：行动中断、认知翻转、代价显现、关系悬置、意象余韵、阶段完成等。先明确语义定义多标签规则，再谈分布；不能凭问号或省略号统计章尾悬念。

## 4. 人物动力与关系

区分显性目标、隐性需要、恐惧、信念、可用资源和不可逾越底线。每条必须有行动或语境支持；心理推断保持可修订。检验角色是否在限制内作出有后果的选择，而非只接收解释、领取任务和配合作者机关。

用关键选择追踪人物弧：早期遇到问题如何反应 → 代价如何击穿旧策略 → 新策略是否真经受检验。暂时退步、表演、欺骗或不可靠叙述不自动等于崩坏。比较关系双方的欲望、信息、筹码和选择权，避免配角只承担工具功能。

## 5. 长期伏笔与认知管理

维护承诺账而非事后神化所有细节：条目、首次出现、当前读者可知、人物可知、加强/误导位置、预期兑现、实际兑现、所付代价、证据强度。明确区分象征复现、世界设定、事后解释与可证明的预先铺垫。

检查回收是否改变行动与意义；重复提到同一物件不自动等于回收。误导须利用可信信息的多义性，不能依靠叙述者无理由隐藏视角人物已知事实。仅看到前半部时将未回收记为“截至当前未见”，不认定烂尾。

## 6. 语言、修辞、白描与留白

在不同功能场景中读句段：冲突、对话、过渡、解释、情绪转折和收束。观察动词/名词具体度、视角感知、叙述距离、句法层次、节奏变化和信息承载。与同书相邻段落比较，再与别书比较，避免将题材差异当作者能力差异。

把修辞效果与成本写在一起：比喻是否增加可感知信息？排比是否形成递进？短句是否真改变节奏？抽象总结是否越过人物实际体验？白描如何靠选择、排列、动作和物件关联产生余味？留白是否仍提供足够线索支持读者推断？这些需要模型逐段阅读，不能由标点/关键词统计直接判定。

## 7. 从分析到原创

采用“问题 → 候选机制 → 适用条件 → 副作用 → 本作选择”。对同一难题允许不同作品给出相反但有效的办法。不要输出统一最佳节奏、每千字修辞额度、固定伏笔间距或角色配置公式。

给原创方案做压力检查：删掉参考作品的专名与表层设定后，是否仍沿用其独特事件顺序、核心谜底或标志性场面？若是，重新设计欲望、约束、冲突解决方式与后果。高层叙事方法可迁移，独特表达与情节组合不做模板。
