# 长篇叙事测量与证据协议 v1

状态（最终）：已收到三部上传稿，完成机械统计、每部36窗模型语义主标与每部4窗独立模型盲复核pilot；技术审计和21项测试通过。双编码者均为模型，不是人类。完整可靠性目标每部8窗未达成，多项一致性低于门槛；结果仅探索性。详细执行记录见 annotation-audit.md 与逐部审计JSON。脚本是可选支撑研究工具，不是每次创作必跑步骤。

## 0. 可交付结论的格式
每条规则采用：数据（样本/全文、分母、区间）→短文本证据（文件、章节、段号/字符偏移）→叙事机制→适用条件→反例/禁用条件→可验收项。证据不够就写“待验证”，不能用名家标签或赞誉补足。正文和大纲分别报告：大纲只能支持事件链和规划意图，不能支持成稿句法、对话比例、感官密度。

五个报告维度允许包含多个独立测量，不能强行压成五个百分比：
1. 结构：冲突、转折、场景、POV；
2. 语言：句长、标点、词汇/语义场；
3. 呈现：对话、独白、潜台词，修辞/意象与白描，感官；
4. 人物：心理驱动与选择代价；
5. 主题：反复命题、矛盾证据与留白。

## 1. 固定语料与边界
- 保存原件、不覆写；记录 SHA-256、文件名、版本、来源、正文/大纲类型、提取方式、提取失败/缺页。清理另存，记录变换。页眉、目录、脚注、批注是否计入必须明确；不把同一稿不同版本当独立作品。
- 规范文本：UTF-8，CRLF/CR 转 LF，Unicode NFC；不繁简转换，不换同义词，不移除正文标点。所有偏移为规范文本的 Python Unicode 码点半开区间 [start,end)，不是原 PDF 字节偏移。
- 汉字：Unicode CJK 统一汉字及扩展、兼容汉字码点；不把中文标点、假名、拉丁字母和数字计作汉字。“〇”另行说明，本协议计入。另报告非空白码点数，防止中英混排被掩盖。
- 段落：一个非空物理行是机械段；连续空行不产生段。不假定 PDF 硬换行就是文学段落，若提取有硬换行须先核验/重建并保留映射。
- 机械句：遇 。！？!? 或连续至少两个 …、至少三个 . 的终止符簇断开；相邻终止符和紧随的闭引号/闭括号归前句；换行强制结束剩余片段。单个 . 不断句，避免小数、缩写；单个 … 不断句。引号内终止符也断句，所以它衡量“标点句”，不是语法句。末尾无终止标点的残片计句并单列数量。
- 分句：在机械句内再按 ，,；;：: 切分，标点附前段；不是句法依存分析。引号内逗号也切分。只含空白/标点的片段不计句/分句。
- 句长/分句长均以汉字数主报，同时报告非空白码点数、中位数、P10/P90、均值、标准差、零汉字句数；不用单一平均值代表节奏。
- 引号层级：匹配 “…”、‘…’、「…」、『…』及 ASCII 双引号。ASCII 单引号不自动识别。栈记录嵌套；引号本身不计引号内字数。未闭合引号仅列异常，不吞并到文末。匹配引号涵盖引用、书面文字、反语等，机械“引号内占比”绝不直接称“对话率”。书名号不作引号。
- 字词：脚本仅给字频、相邻二字串，二字串不跨标点/空白/行。它们不是“词汇量”。若使用分词，须指定工具、词典、版本与人名处理；只在等长抽样上比较词汇丰富度，并报告敏感性。语义场必须模型语义上下文编码，关键词检索只召回候选。

## 2. 全量机械统计（可复现）
逐文件、逐可信章节运行；正文与大纲不混合，三部作品分别统计后再比较。
- 汉字与非空白码点总数、物理段数、标点句/分句数、长度分布；各标点按字符计数和每千汉字频率（……为两字符，另可报告省略号簇事件，不混用）。
- 匹配引号内部汉字的并集占比、未闭合/错配引号异常；嵌套只计一次。
- 高频字、二字串及其频率；章节可视化用同一分母。异常全量列出，模型语义回看后才修改清理稿。
- 原型 analyze_text.py 只执行上述有限机械口径，不“测出”冲突、心理、隐喻或潜台词。输出包含算法版本与规范文本散列。ASCII 双引号在长文本可能表示英寸/程序符号，异常须核验。

## 3. 分层抽样与覆盖率
### 3.1 概率样本，用于有限外推
每部正文独立按叙事顺序的累计汉字将可分析正文分为开/中/末三个等长区间；把各层构造成约 600 汉字的不重叠连续核心窗口，尾窗保留并记录长度。窗口可在段落边界附近调整，但必须记录确切分割规则与偏移，不能为了“好段落”调整。上下各读 300 汉字作语境，不计入核心分母，不跨窗口重复计核心。

每层简单随机不放回抽 12 窗（共 36 窗/部，约 21,600 字）；不足 12 窗则全取。种子固定为 20261012，保存完整窗口总体、排序、抽中 ID 和抽样脚本/算法版本。三部最低目标约 108 窗，不声称这已执行。样本须覆盖各层，不保证覆盖全部章节；记录实际涉及章数/总章数、核心汉字/全文汉字、窗数/总体窗数、可编码率。若文本较短则直接全标；若资源不够，报告实际完成量并降级结论，不伪称达到最低目标。

估计单元为窗口；比例按层总体规模加权，以估计的事件/汉字总量之比报告，不能简单平均各窗比例。至少 2 窗/层才估计层内方差。置信区间用层内窗口聚类重采样（10,000 次；样本已全取的层固定），同时提供未加权原始分子/分母。稀有事件、只有一章承载的模式或极少正例不适用普通 bootstrap 的精确宣传；只报观察值、证据位置和不确定性。三部是三个案例，不能当作某类型文学总体随机样本。

### 3.2 目的样本，只解释机制
另取首个重大承诺、重大失败、中点改道、高潮选择、收束等关键场景（每部最多 6 个，实际有则选）。先依据全文/可靠大纲识别，再定位正文；列选择依据和定位置信度。与随机样本重叠时去重，不将目的样本合并进全文频率估计。关键场景只支持“此处如何起作用”，不能外推整本发生率。

场景级结构、长期心理弧线、主题留白不能仅凭 600 字窗外推。若未通读和建立完整场景/事件账本，应明确“局部证据”，以大纲核对顺序但不替代正文证据。

## 4. 模型语义编码表与重叠口径
每条编码记录：作品、文件 SHA、章/段、核心窗 ID、start/end、引文、标签、理由、反证、确定/不确定、编码者、版本。引用只截足够核验的短段；记录更大语境位置供复核。

| 测量 | 操作定义与分母 | 不得替代的捷径 |
|---|---|---|
| 场景/冲突 | 场景以时间、地点或持续行动目标的实质切换界定；冲突必须列行动者、欲求、阻力、代价。频率按已完整标注场景数，非句数 | 出现“敌”“怒”不等于冲突 |
| 转折 | 新信息/决定/结果使目标、可行策略、权力或读者因果预期改变；记录前状态→触发→后状态及后文响应 | 但是、忽然不等于转折；悬念句不必有状态变化 |
| POV | 叙述人称与聚焦分开；每场景标可进入谁的意识、是否外部/变动聚焦。跨场景转换与场内越界分别计 | “他想”不能单凭词面证明全知或头脑跳转 |
| 对话/独白 | 实际说出的话、内心直接引语、间接心理叙述、书面引用、其他引用分开；模型语义确认汉字跨度并取并集。对话占比=说出话语汉字/核心汉字 | 所有引号不全是对话，无引号也可能是对话 |
| 潜台词 | 对话轮或行动中表层内容与语境支持的意图/关系信号不同；标表层、隐含解释、支持证据及竞争解释。按可判断话轮报告；上下文不足归未知 | 省略号、反问、沉默、心理关键词都不是真值 |
| 隐喻/明喻 | 明确源域→目标域的跨域映射；明喻单列，字面比较排除。按事件/千汉字和修辞跨度并集汉字/核心汉字双报 | “像”“仿佛”仅候选；无连接词亦可成隐喻 |
| 意象/象征/白描 | 意象须可感知形象并说明叙事功能；象征须有跨处复现或对照支持额外意义；白描为观察性直接呈现且该跨度不依赖修辞映射，可与意象共存。各自跨度并集/核心汉字 | 白描不是“非隐喻全部文字”；主题词重复不自动等于象征 |
| 感官 | 视觉/听觉/嗅觉/味觉/触觉/温度/身体内感/运动觉分别标；可多标签。报各类事件/千汉字、跨度占比、感官跨度并集 | 不能把所有标签百分比凑 100%；抽象“痛苦”不自动是身体痛觉 |
| 心理驱动 | 具体欲求、信念/误信、恐惧、价值冲突、策略、选择、代价；需行为或直接内心证据，区分叙述者断言和推断 | “怕”“想”频次不是动机深度；单窗不能证明人物弧线 |
| 主题与留白 | 主题用可争论的命题描述，至少两处支持和一处矛盾/边界证据；留白记录明确提出而未回答的问题、叙事效果与阅读至何处仍未回答 | 没写到不必是有意留白，开放结局不等于所有线索未交代 |

跨度跨核心边界时只计核心内字符；事件以其锚点（首次实现标签所需证据的位置）归一个窗，避免跨窗重复；若完整事件不可见记“语境不足”。同类重叠跨度取并集；跨类保留交集，另报并集和交集。若用户需要感官“权重”，只可另外给多标签事件的分数分配（一个事件有 k 类则各得 1/k），注明这只是统计分配，不是感受强度。

## 5. 盲标与可靠性
先选 6 个窗/部作训练（不用于独立一致性分数），两个独立模型编码者读同一手册，独立编码后修订定义并冻结。正式随机样本中再盲抽至少 20%（每部至少 8 窗且三层均有），第二编码者看不到首人的标签、汇总和预期结论。资源不足只能单标时如实说明，不能把同一模型自检称两个独立模型编码者盲标。
- 固定单位上的二元标签：逐标签报告原始一致率、正例一致率、负例一致率与 Cohen κ；极低流行率/全零时 κ 无定义或不稳定，明示。
- 多标签不压成互斥标签；分别评估。跨度标注用字符级 precision/recall/F1，并报告严格事件边界匹配或容差规则；不能将跨度 F1 当因果解读一致性。
- 建议可靠性门槛：关键标签 κ≥0.67 且正例一致率≥0.75，跨度 F1≥0.80；这些是本项目工作门槛，不是通用真理。未达标则合并含混类别/补训练，冻结新版本后重标受影响样本；不事后挑掉分歧窗来提高分数。
- 保留原始独立记录，再第三步协商裁决；裁决后记录用于最终统计，裁决前记录用于可靠性报告。尚未发生的盲标绝不填写假分数。

## 6. 验收与停止条件
1. 三部文件身份、类型、完整性已核对，异常提取有披露。
2. 全量结果能以固定版本脚本重跑；单元测试通过；模型语义对照至少 10 段边界和引号。
3. 样本总体、种子、核心边界、标注表、覆盖率、实际样本量齐全；目的样本与概率样本分开。
4. 每个结论指向真实短引文和位置；同一标签跨作品口径一致；未知不当作负例。
5. 所有比率标分子、分母、样本/全文；多标签不硬加总为 100%；区间只涵盖抽样误差，不假装涵盖编码或提取误差。
6. 规则为可迁移机制，不把源作品高频词或情节做机械复制模板；至少列一个失败/不适用情形和可检查的编辑动作。
7. 找不到正文、只拿到片段、提取破损、未完成样本或可靠性不足时，交付受限结论和缺口，不补编精确数据。
