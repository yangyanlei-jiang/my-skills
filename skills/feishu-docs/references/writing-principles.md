# 写作原则：从内容结构到原生格式

来源：[《如何写好飞书文档？》](https://www.feishu.cn/hc/zh-CN/articles/360049067898-%E5%A6%82%E4%BD%95%E5%86%99%E5%A5%BD%E9%A3%9E%E4%B9%A6%E6%96%87%E6%A1%A3)。作者为标果科技平台运营负责人王紫藤，投稿于 2021 年 1 月；页面显示最后更新于 2024-08-20。2026-10-12 阅读核对。下列内容为归纳，不转载原文。

## 提炼的原则

- 先组织内容和逻辑，再用格式表达结构。
- 标题应概括章节，并组成清晰的目录；正文不应为了视觉醒目进入目录。
- 正文重点用加粗或高亮，完成后检查目录有无误设为标题的正文。
- 有序列表表达步骤，无序列表表达并列项；缩进表达从属关系。
- 按内容选择任务、引用、代码、表格等原生块，不必堆满所有格式。
- 区分文档表格、电子表格与多维表格，根据目的选择；本技能的表格要求是文档富文本表格。

## 在当前工具中应用

用户补充的总原则是：**能使用原生的就用原生的，保证编写输出简约。** 按文档规模决定是否需要章节；短文可以直接使用正文和列表。仅在信息表达需要时增加表格、高亮块或图表，避免固定模板和过度装饰。

写完后同时检查内容和结构：信息有无重复，标题是否必要，目录是否符合章节，风险是否醒目，表格是否适合横向比较，代码和引用是否可辨。

文章中的旧按钮图标、容量限制、快捷键位置和功能清单属于当时界面，不能当成当前 API 契约。操作时检查当前工具或编辑器；涉及格式细节再读 [原生格式](native-format.md)。以当前官方文档、工具契约和实际结果为准。

使用 Markdown 快捷键可以提高编辑效率，但不能推导出连接器支持同样语法，也不能代替原生结构验收。
